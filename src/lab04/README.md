# Задание A — `io_txt_csv.py`

В файле `io_txt_csv.py` реализованы функции для чтения текстовых файлов и записи данных в CSV.

## `read_text()`

```python
read_text(path, encoding="utf-8")
```

Функция принимает путь к текстовому файлу и возвращает его содержимое одной строкой.

По умолчанию используется кодировка `UTF-8`.

При необходимости можно указать другую кодировку:

```python
read_text("src/data/lab04/input.txt", encoding="cp1251")
```

Если файл не существует, возникает `FileNotFoundError`.

Если файл невозможно прочитать в указанной кодировке, возникает `UnicodeDecodeError`.

---

## `write_csv()`

```python
write_csv(rows, path, header=None)
```

Функция записывает переданные строки в CSV-файл.

Если передан параметр `header`, он записывается первой строкой файла.

Пример:

```python
write_csv(
    [("привет", 2), ("мир", 1)],
    "src/data/lab04/report.csv",
    ("word", "count")
)
```

Результат:

```csv
word,count
привет,2
мир,1
```

---

## `ensure_parent_dir()`

```python
ensure_parent_dir(path)
```

Создаёт родительские директории для указанного пути, если их ещё нет.

# Задание B — `text_report.py`

Скрипт выполняет обработку текста:

1. читает текст из файла;
2. нормализует текст;
3. разбивает текст на слова;
4. подсчитывает частоту слов;
5. получает топ наиболее частых слов;
6. записывает результат в CSV.

Для обработки текста используются функции:

```python
normalize()
tokenize()
count_freq()
top_n()
```

## Выбор кодировки

По умолчанию используется кодировка `UTF-8`.

Для файла в кодировке `cp1251`:

```powershell
python -m src.lab04.text_report --in src/data/lab04/input.txt --encoding cp1251
```

Например, если файл содержит:

```text
Привет
```

после обработки получается:

```text
привет: 1
```

# ★ Дополнительное задание — несколько файлов

Реализована обработка нескольких текстовых файлов за один запуск.

Для каждого файла подсчитывается отдельная статистика, а также создаётся общий отчёт по всем файлам.

Пример файлов:

### `a.txt`

```text
Привет мир
```

### `b.txt`

```text
Привет, привет!
```

## Запуск

```powershell
python -m src.lab04.text_report --in src/data/lab04/a.txt src/data/lab04/b.txt --per-file src/data/lab04/report_per_file.csv --total src/data/lab04/report_total.csv
```

После выполнения создаются два отчёта.

### `report_per_file.csv`

```csv
file,word,count
a.txt,мир,1
a.txt,привет,1
b.txt,привет,2
```

### `report_total.csv`

```csv
word,count
привет,3
мир,1
```

Для получения только имени файла из полного пути используется:

```python
Path(path).name
```

Например:

```text
src/data/lab04/a.txt
```

преобразуется в:

```text
a.txt
```
