# Лабораторная работа №4 — Работа с файлами TXT и CSV

## Описание

В лабораторной работе реализована работа с текстовыми и CSV-файлами.

Программа читает текст из файла, нормализует его, разбивает на слова и подсчитывает частоту каждого слова. Для обработки текста используются функции из лабораторной работы №3.

Результат сохраняется в CSV-файл в формате:

```text
word,count
```

Также поддерживается выбор кодировки входного файла.

## Файлы

- `io_txt_csv.py` — чтение TXT-файлов и запись данных в CSV.
- `text_report.py` — обработка текста и создание отчёта.
- `src/data/lab04/` — входные файлы и результаты работы.

## Запуск

Запуск выполняется из корня проекта.

Обычный запуск:

```powershell
python -m src.lab04.text_report
```

С указанием входного файла:

```powershell
python -m src.lab04.text_report --in src/data/lab04/input.txt
```

С указанием кодировки:

```powershell
python -m src.lab04.text_report --in src/data/lab04/input.txt --encoding cp1251
```

С указанием выходного файла:

```powershell
python -m src.lab04.text_report --in src/data/lab04/input.txt --out src/data/lab04/report.csv
```

## Принцип работы

1. Текст считывается из файла.
2. Выполняется нормализация и токенизация.
3. Подсчитывается частота слов.
4. В консоль выводится статистика текста.
5. Результат записывается в CSV-файл.

## ★ Работа с несколькими файлами

Дополнительно реализована обработка нескольких файлов за один запуск.

Создаются:

- `report_per_file.csv` — статистика отдельно по каждому файлу;
- `report_total.csv` — общая статистика по всем файлам.

Пример запуска:

```powershell
python -m src.lab04.text_report --in src/data/lab04/a.txt src/data/lab04/b.txt --per-file src/data/lab04/report_per_file.csv --total src/data/lab04/report_total.csv
```

## Вывод

В ходе работы была реализована обработка текстовых файлов, подсчёт частоты слов и сохранение результатов в формате CSV. Также была добавлена поддержка различных кодировок и обработки нескольких файлов.
